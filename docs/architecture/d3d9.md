# PE32 D3D9 调用与资源契约

`Direct3DCreate9` 接受 SDK 31/32，返回进程拥有的工厂对象；其他 SDK 返回 NULL。234 个 COM 方法的顺序及 stdcall 参数宽度使用固定的 Hangover ABI 表。内部方法只通过对象 vtable 注册，不能通过 DLL 导出查询绑定。AMD64 保持未提供。

新旧入口共用 `src/graphics/d3d9.rs` 及其子模块中的对象、引用、资源、状态块、顶点布局、VS2/PS2 和光栅处理体。Wasm 适配连接当前 VMM、进程堆、方法网关及 USER；原生适配保留 Metal、文件诊断和首次绘制时间。共享核心不依赖旧 CPU 执行器、IR、原生内存或宿主图形系统。Wasm 使用串行软件光栅。

支持一个虚拟 adapter、受限固定管线、三角形 list/strip/fan、BGRA8/XRGB8、D24S8、一层纹理、两个 texture stage、stream 0、16/32 位索引及已有声明布局。VS2 支持现有 MOV/DP4 和声明子集；PS2 保留有界的算术、采样和输出规则。状态、opcode、寄存器、格式和多重采样等超出范围时返回既有 HRESULT。234 个槽均有调用适配，其中 169 个进入既有处理分支，65 个旧实现没有处理体的槽返回 `D3DERR_NOTAVAILABLE`；逐项能力见 [接口台账](../api-migration.json)。

资源与 COM 指针来自当前进程堆；parent/child pin、外部引用 lease、锁及共享像素 buffer 决定存活时间。对象限额 4096，单 backing 最大 64 MiB，总 backing 最大 256 MiB。Reset 在校验和新资源准备完成后替换隐式 surface，保留 swapchain 身份；仍持有默认池资源或 swapchain 的外部引用时拒绝重置。EndStateBlock 分配失败保留录制，成功后转移成员和引用。

非空客体地址的访问失败保留当前 VMM 的地址、宽度、权限和故障种类，交由统一服务边界暂停；HRESULT 失败使用接口约定的返回值和空输出。创建、QueryInterface 及 GetContainer 在确定 HRESULT 失败后清空输出；可恢复的输入、输出或分配访存故障保持原输出。多输出查询和颜色/深度写入先完成批次访问检查。临时 vtable/对象/资源分配失败会回收未发布对象，重试沿用有效引用和录制状态。

Present 读取未锁定的 back buffer，按合法 source rectangle 最近邻缩放到当前客户区，成功写入后递增帧数。目的区域必须是整个客户区，dirty region 仍不支持。输出与 GDI DC 共用同一窗口位图，已有 DC 可立即读取或修改呈现像素；`windowPixels()` 提供 RGBA 快照。根进程和子进程的像素可按 PID/HWND 送入 BrowserPresenter；D3D9 的 GPU 加速和完整 shader/格式覆盖仍缺失。

定向验证入口：

```sh
node crates/wire-wasm/tests/d3d9.mjs
cargo test --locked --offline --test win32 d3d9_ --target-dir target/resident
```

两者均使用项目源码生成的确定性输入。真实 Metal 设备比较继续位于原生 ignored 测试，需要显式选择；常规测试不依赖本机 GPU 或外部游戏数据。
